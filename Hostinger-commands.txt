Hostinger production deployment quick reference

Do not store server passwords, database passwords, JWT secrets, or admin
passwords in this file. Keep production secrets only in /root/school-app/.env
on the server.

SSH:

ssh root@72.62.250.216

Pass: StarScl@2026

Project:

cd /root/school-app

Deploy:

./deploy-production.sh

Manual status check:

docker compose --env-file .env -f compose.production.yml ps

Logs:

docker compose --env-file .env -f compose.production.yml logs --tail=150 backend
docker compose --env-file .env -f compose.production.yml logs --tail=100 nginx
docker compose --env-file .env -f compose.production.yml logs --tail=100 postgres

Never run docker compose down -v unless you intentionally want to delete
PostgreSQL data and certificate volumes.
